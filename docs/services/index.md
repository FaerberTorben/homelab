# Service catalog

The catalog groups active services by the outcome they provide. It is intentionally not a list of endpoints, credentials, or every dependency.

| Area | Services |
|---|---|
| Home automation | Home Assistant, Node-RED house, MQTT, Zigbee2MQTT, ESPHome, Jarvis voice |
| Media & documents | Media Docker, Immich, Jellyfin, Servarr, Paperless-ngx, Automatic Ripping Machine |
| Access & security | Vaultwarden HA, Authentik, Cloudflared, ntfy |
| Automation & AI | Hermes Agent, n8n, Ollama, Open WebUI, quant trading, MT5 terminal |
| Observability | Prometheus, Grafana, Uptime Kuma, PVE exporter, Homepage |
| Utilities | Scanner, print service, Rackula, UPS monitoring, Cloudflare DDNS |

## Service ownership

A service is documented by its purpose and platform placement. Runtime configuration, private paths, dashboard URLs, credentials, and operational identifiers remain outside this public repository.
